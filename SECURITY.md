# Security Policy

## Reporting a vulnerability

Please do not report security issues in public GitHub issues, discussions, or pull requests.

Report them privately through GitHub Security Advisories instead: open the repository's **Security** tab and click **Report a vulnerability**.

Include what you found, how to reproduce it, and the impact you expect. You will get a reply as soon as possible. Once a fix is ready, the advisory will be published with credit to you, unless you prefer otherwise.

## Supported versions

The project is in early development. Only the latest code on the `main` branch is supported.
